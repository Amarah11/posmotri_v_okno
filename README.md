# Проектная работа "Посмотри в окно"

Стек: HTML, CSS, JS

Структура проекта:
- fonts/ — файлы шрифтов и файл для их подключения
- scripts/ — файлы скриптов
- styles/ — папка со стилями проекта
- index.html — файл с версткой проекта

## Описание проекта 

Проект Посмотри-в-окно представляет из себя SPA с получением данных из стороннего API. Данные представляют из себя кликабельные карточки видеозаписей, которые пользователь может просматривать.
Есть возможность сортировки приходящих данных по времени суток и городу.

В этой проектной работе мне продстояло написать CSS для уже работающего приложения «Посмотри в окно». <br>
Я дополнил файл style.css так, чтобы интерфейс соответствовал макету проекта. <br> Проект выполнен на основе следующего макета: https://www.figma.com/design/ApJjZAA3pBv2tCZM9E2ul2/2-спринт.-Посмотри-в-окно?node-id=0-1&p=f&t=Z6d7d8ntzuuATzw3-0

В стартовом репозитории я получил готовые файлы: <br>
всю HTML-разметку; <br>
CSS для компонентов прелоадера, кастомного скроллбара и вывода ошибки; <br>
файлы шрифтов и стили для них; <br>
файл со скриптом, в котором описана логика работы приложения.

## Описание функциональности приложения
При загрузке страницы скрипт получает данные из внешнего источника, отрисовывает пять карточек с видео и кнопку, чтобы подгрузить дополнительные карточки. Ещё он подставляет адрес первого из загруженных роликов в тег `video` внутри крупного блока на странице.
Скрипт отслеживает клик по карточкам и меняет текущее видео в зависимости от выбранной карточки.
Также скрипт следит за отправкой формы. После отправки он ищет в базе данных совпадения по введённым параметрам и перерисовывает страницу с данными, полученными из нового запроса.
В случае ошибок на место блока с видео подставляется блок с сообщением об ошибке. А пока идёт поиск, в блоки с видео и карточками подставляются прелоадеры, отображающие анимацию процесса загрузки.

## Устройство HTML-кода
В коде четыре шаблона `template`:
1.  Шаблон пункта списка с карточкой видео — в него подставляются данные для создания нужного количества карточек.
2.  Шаблон прелоадера — пока данные загружаются, для зон, где будет контент, создаются экземпляры прелоадера. Когда контент готов, прелоадеры убираются.
3.  Шаблон кнопки «Показать ещё» — кнопка ставится в конец списка карточек каждый раз, когда доступны дополнительные видео. Нажатие на кнопку подгружает пять дополнительных карточек.
4.  Шаблон блока с ошибкой — вставляется на страницу при возникновении ошибки, текст на шаблоне зависит от типа ошибки.
